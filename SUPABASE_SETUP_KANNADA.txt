Client permissions:
Clients can submit enquiries, choose a preferred project date, and view project status.
Team edit area is protected by the trial team edit code; clients are not given team-edit access.

Database:
Trial mode works immediately using browser storage.
For shared real-time Supabase data, database.js must contain the Supabase project URL and anon key.
Do NOT put a service-role key in the website.

Payment:
The payment page records transaction details in the local trial record and can post to Supabase when configured.
No real payment is charged by the demo button.

AI:
The floating 3FS AI assistant is specific to 3FS services, pricing, enquiries, dates, payments, team workflow and client status.
